# Data

## Contents

- `Data_Set_S1.txt`: final, complete ToC2ME focal mechanism catalog for this study (2526 data rows plus one header row). Columns are `origin_time evla evlo depth strike dip rake evid mag`, where `origin_time` is the event origin time string, `evla`/`evlo`/`depth` are the event latitude (degrees), longitude (degrees), and depth (km), `strike`/`dip`/`rake` are the focal mechanism angles (degrees), `evid` is the event identifier, and `mag` is the magnitude.
- `ToC2ME_Testing_data_for_model_20241022/`: model testing arrays (`datall.npy` for waveforms and `polall.npy` for polarity labels).
